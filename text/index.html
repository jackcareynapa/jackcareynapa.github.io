About Me

Side A

Napa, California

I grew up in Napa, among vineyards that change with the seasons: green in spring, gold at harvest, bare by winter. The hills around them go gold every summer, and I've spent a lot of summers finding out what's past the next one.

My idea of a good afternoon is driving around with no particular plan. I go on Google Earth looking for swimming holes, then go and see whether they're real. Some of them come with cliffs. I jump.

My favourite place in the world is Mt. Tamalpais at sunset.

Side B

Creativity and computation

It started with Minecraft: a world where you could build anything, which made me want to build the world itself. Now I study computer science at Duke, and I believe creativity and computation belong together.

The other half of my week is improv and theater, with Duke Improv and Hoof 'n' Horn. Improv taught me that the best moment in a scene is the one nobody saw coming, and that's how I design: subvert the expectation, stay unpredictable, keep people on their toes.

The purest version so far is The Worst Tutorial Ever, a PICO-8 tutorial that lies to you, swaps your controls and never lets you skip it.

Wikinaut

Wikinaut

A space-themed navigation game for Wikipedia. Name a destination article and your ship flies the shortest link path there, hop by hop, through the real links on each live page.

Python · Flask · JavaScript · SQLite · Fly.io

The backend is a fork of Six Degrees of Wikipedia (jwngr/sdow) by Jacob Wenger.

Open project · View source

How to play

  1. Set coordinates. Open any English Wikipedia article and type a destination into the console. Autocomplete helps.
  2. Chart course. The backend finds the shortest link path and draws it as a star map. When several routes tie, the pager steps through them.
  3. Launch. The ship flies to each next link on the page and jumps through hyperspace to the next article, until you arrive.

How it works

  1. Userscript: console + flight on the live page
  2. Flask API: Docker on Fly.io
  3. Bidirectional BFS: memory-mapped CSR arrays
  4. SQLite link graph: built from Wikipedia dumps

  • Rebuilt the multi-GB data pipeline in Python 3 for Wikipedia's 2024 schema change, which silently broke upstream builds.
  • Live-page link matching handles redirects, two page renderers and collapsed sections, with a direct-URL fallback.

The Worst Tutorial Ever

The Worst Tutorial Ever

A platformer tutorial that breaks itself as you play. The friendly narrator starts lying, the screen glitches, and the controls swap, lock and reshuffle.

PICO-8 · Lua · Prototype · Solo · itch.io disclosure: AI-assisted code

Open project

How to play (this leaflet is unreliable)

  1. Follow the narrator. The narrator gradually corrupts and turns on you.
  2. Learn the controls. Directions swap, backtracking locks, and buttons remap every 3 seconds.
  3. In a hurry? Press Skip Tutorial. It never works.

Meme Studio

Meme Studio

Upload an image, add context, get three captioned memes.

Next.js · AWS Lambda · Amazon S3 · OpenAI API

Open project · View source

How it works

  1. Browser: describe + upload
  2. Next.js on Vercel: creates the job, asks OpenAI for captions
  3. Amazon S3: presigned direct upload, job status as JSON
  4. Lambda + Sharp: S3-triggered; renders three JPEGs

No long-running app server: job state lives in S3 and the browser polls for it.

Napa Valley Winery Map

Napa Valley Winery Map

An interactive map of Napa Valley wineries, built from winery profile pages and shown as structured profiles on a Mapbox GL map.

Python · Firecrawl · Mapbox GL JS · GeoJSON

Open project · View source

How it works

A four-step data pipeline, each step a small Python tool.
